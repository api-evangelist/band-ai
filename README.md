Band (BAND AI) is enterprise-grade interaction infrastructure for distributed AI agents. Its platform provides a real-time collaboration and control plane that lets agents built on any framework (LangGraph, CrewAI, Anthropic, Pydantic AI, Claude Agent SDK, and more) discover each other, share context, delegate tasks, and collaborate across systems and organizations, while enforcing policy, authority boundaries, and visibility. Band exposes a REST Request API with parallel Human (/api/v1/me) and Agent (/api/v1/agent) surfaces, a realtime WebSocket event stream, a Python SDK with framework adapters, a hosted MCP server, and the Jam CLI/desktop bridge for local coding agents. Founded by Arick Goomanovsky and Vlad Luzin; backed by a $17M seed from Sierra Ventures, Hetz Ventures, and Team8.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Band AI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
